# Closeout M17 — Post-review fixes of M11-M16

- Closed (UTC): 2026-09-19
- main SHA: 1d69922a486284d8bdd4a9fbd3ab65d0dc01a6cb

Exit criteria, read from the milestone's own description on the day above. The first
and the third are ticked. The second — every sub-issue of #201 that is not blocked on
#148 or #172 is merged — was still unticked when this file was written, and what it
asks for holds: #201 carries twenty-four sub-issues, every one of them a row below,
every one closed by a merged pull request.

No criterion is what kept this phase open. M17 exists to hold post-review fixes of
M11-M16, and every review of an M17 pull request files more M17 issues, so the phase
has no fixed point by construction, and `close-milestone.mts` refuses
`milestone:open-issues` while a single one is open. The twenty-four sub-issues of #201
became forty-one merged issues, seventeen of them filed against mechanisms this phase
had already touched. The cut recorded in `## Left out` is what ended it. This file is
a dated snapshot at the SHA above, not a claim that nothing further will be found in
what the phase shipped.
