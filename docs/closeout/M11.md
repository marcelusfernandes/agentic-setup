- What the same pass found about the gate this phase built, which is the part worth
  reading twice. The reviewed-SHA pin of #144 was proved live: runtime proof P3 records
  it refusing a land after an unreviewed push, before the merge rather than after it,
  and finding D11 records the shape it prevents — a queued auto-merge merging a later
  conflict-resolution commit no review had seen. Its remaining gap is that the
  `approved` mode never compares the approving review's commit, so a stale approval
  still merges a new head (#238, open). The review mode recorded by #148 (PR #251) was
  found reachable around from the other side: `land`'s docs mode reads the `type:docs`
  label and not the changed paths, so a change to a test or a contract card lands
  unreviewed (#308, open). Reviews of this phase's pull requests also produced #212,
  #213, #214, #229, #234 and #238 in M17, and the report of PR #271 revisits the #147
  bullet above, confirming it was closed as a duplicate although nothing else asks for
  the reviewer identity — resolved as the owner decision recorded in register item 18
